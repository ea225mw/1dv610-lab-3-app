# Requirements for String Works Editor

| ID  | Description                                                                                                                           | Testcase   |
| --- | ------------------------------------------------------------------------------------------------------------------------------------- | ---------- |
| R1. | It should be possible to type text and paste text in a textarea.                                                                      | 1, 2       |
| R2. | The shortest word in the text is shown in a table along with the number of letters in that word.                                      | 3          |
| R3. | The longest word in the text is shown in a table along with the number of letters in that word.                                       | 4          |
| R4. | The most frequently used letter in the text is shown in a table along with the number of occurrences of that letter.                  | 5          |
| R5. | The most frequently used letter (CASE SENSITIVE) in the text is shown in a table along with the number of occurrences of that letter. | 6          |
| R6. | The total number of words in the text should be presented.                                                                            | 7          |
| R7. | The total number of letters in the text should be presented.                                                                          | 8          |
| R8. | It should be possible to pass a phrase (word or single letter) and get the number of occurrences of that phrase.                      | 9          |
| R9. | It should be possible to sort the words in the text in alphabetically order (ascending or descending).                                | 10, 11, 12 |
